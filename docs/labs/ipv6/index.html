ff02::1:ff0c:417a
Interface ID (64 bit หลัง)
0008:0800:200c:417a

กฎย่อ: ตัด 0 นำหน้าในแต่ละกลุ่ม · แทนกลุ่ม 0 ที่ต่อกันยาวที่สุด (≥ 2 กลุ่ม) ด้วย :: ได้ครั้งเดียว · ถ้ายาวเท่ากันย่อช่วงแรก · ใช้ตัวพิมพ์เล็ก

  1. 1. MAC: 00 e0 fc 12 34 56
  2. 2. แทรก FFFE ตรงกลาง: 00 e0 fc ff fe 12 34 56
  3. 3. byte แรก 00 = 00000000 → กลับ bit ที่ 7 (U/L) → 00000010 = 02
  4. 4. Interface ID: 02e0:fcff:fe12:3456
Link-local (FE80::/64 + EUI-64)
fe80::2e0:fcff:fe12:3456
Global (prefix + EUI-64)
2001:db8:1:0:2e0:fcff:fe12:3456

VRP: ipv6 address auto link-local สร้าง link-local แบบนี้ · ipv6 address 2001:db8:1:: 64 eui-64 ใช้ prefix + EUI-64
