Interactive Labs

จำลองการทำงานของโปรโตคอลแบบโต้ตอบได้ เพื่อเข้าใจกลไกจริง ไม่ใช่แค่ท่องจำ

  • Lab 1 · M3Subnet Calculator + Drillคำนวณ subnet และฝึกทำโจทย์ subnet/VLSM แบบจับเวลา
  • Lab 2 · M5OSPF Visualizerneighbor state machine, DR/BDR election และคำนวณ SPF cost
  • Lab 3 · M7STP Simulatorทาย root bridge, root port, designated port และ blocked port
  • Lab 4 · M6VLAN Frame Tracerติดตาม frame ผ่าน access/trunk/hybrid ว่า tag ถูกใส่หรือถอดที่ไหน
  • Lab 5 · M8ACL Matcherใส่ rule กับ packet แล้วดูว่า match rule ใด รวมถึง default action
  • Lab 6 · M9NAT Translation Tableเปรียบเทียบ Static NAT, NAPT, Easy IP และ NAT Server
  • Lab 7 · M12IPv6 Address Toolย่อ/ขยาย address, สร้าง EUI-64 และบอกชนิด address
