Lab 5: ACL Matcher

ใส่ rule กับ packet แล้วดูว่า match rule ใด รวมถึง default action

บทเรียนที่เกี่ยวข้อง: M8 ACL & AAA

ตัวอย่าง:

1. เขียน ACL

Advanced — 5-tuple

รูปแบบ: rule [id] permit|deny <ip|tcp|udp|icmp> source <ip> <wildcard>|any destination … destination-port eq <port> — ไม่ใส่ id จะได้ค่าอัตโนมัติตาม step 5

2. packet ที่จะทดสอบ

ACL ถูกเรียกใช้โดย

3. ผลการ match (ตรวจจาก rule ID น้อยไปมาก)

  1. rule 5 permit tcp source 10.1.10.0 0.0.0.255 destination 10.1.100.10 0 destination-port eq 80✗ destination ไม่ตรง
  2. rule 10 permit tcp source 10.1.10.0 0.0.0.255 destination 10.1.100.10 0 destination-port eq 443✗ destination ไม่ตรง
  3. rule 15 deny ip source 10.1.10.0 0.0.0.255✓ MATCH → deny
ผลลัพธ์: rule 15 deny → ทิ้ง packet
