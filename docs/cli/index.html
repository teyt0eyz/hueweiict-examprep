VRP CLI Cheatsheet

คำสั่ง Huawei VRP ที่ใช้บ่อย 180 คำสั่ง ค้นหาได้และกรองตามหัวข้อ · prompt บอก view: <R1> = user view, [R1] = system view, [R1-…] = view ย่อย

180 คำสั่ง

พื้นฐาน VRP

บทเรียน M2 →
  • <HUAWEI>system-view

    เข้า system view เพื่อตั้งค่า

  • [HUAWEI]sysname R1

    ตั้งชื่ออุปกรณ์

  • [R1]quit

    ถอยออกหนึ่งระดับ

  • [R1-GigabitEthernet0/0/0]return

    กลับไป user view ทันที (Ctrl+Z)

  • [R1]undo info-center enable

    undo = ยกเลิก/ลบค่าที่ตั้ง (ตัวอย่าง: ปิด log บนหน้าจอ)

  • <R1>save

    บันทึก config ลง flash (vrpcfg.zip)

  • <R1>display current-configuration

    config ที่กำลังทำงาน

  • <R1>display saved-configuration

    config ที่บันทึกไว้

  • <R1>display version

    รุ่น ซอฟต์แวร์ และ uptime

  • <R1>display this

    config ของ view ปัจจุบัน

  • <R1>reset saved-configuration

    ล้าง config ที่บันทึกไว้ (ใช้ก่อน reboot เพื่อเริ่มใหม่)

  • <R1>reboot

    รีสตาร์ทอุปกรณ์

  • <R1>startup saved-configuration backup.cfg

    เลือกไฟล์ config ที่จะใช้ตอนบูตครั้งถัดไป

  • <R1>display startup

    ไฟล์ระบบและ config ที่ใช้ตอนบูต

  • <R1>dir

    รายการไฟล์ใน flash

  • <R1>screen-length 0 temporary

    ปิดการแบ่งหน้า (---- More ----) ใน session นี้

  • [R1]clock timezone BKK add 07:00:00

    ตั้ง time zone

การจัดการและ login

บทเรียน M2 →
  • [R1]user-interface console 0

    เข้า console port

  • [R1-ui-console0]authentication-mode password

    ใช้ password อย่างเดียว

  • [R1]user-interface vty 0 4

    virtual terminal สำหรับ Telnet/SSH 5 session

  • [R1-ui-vty0-4]authentication-mode aaa

    ตรวจด้วย AAA (username + password)

  • [R1-ui-vty0-4]user privilege level 15

    กำหนดสิทธิ์ของผู้ใช้ที่ login ผ่าน VTY

  • [R1-ui-vty0-4]protocol inbound ssh

    อนุญาตเฉพาะ SSH

  • [R1-ui-vty0-4]acl 2000 inbound

    จำกัด IP ที่ login ได้ด้วย ACL

  • [R1]telnet server enable

    เปิด Telnet server

  • [R1]stelnet server enable

    เปิด SSH server

  • [R1]rsa local-key-pair create

    สร้าง key สำหรับ SSH

  • [R1]ssh user admin authentication-type password

    กำหนดวิธียืนยันตัวผู้ใช้ SSH

  • <R1>display users

    ผู้ที่ login อยู่

Interface และ IP

บทเรียน M3 →
  • [R1]interface GigabitEthernet 0/0/0

    เข้า interface

  • [R1-GigabitEthernet0/0/0]ip address 192.168.1.1 24

    ตั้ง IP (ใส่ prefix หรือ mask ก็ได้)

  • [R1-GigabitEthernet0/0/0]ip address 10.1.1.1 24 sub

    IP สำรอง (secondary)

  • [R1-GigabitEthernet0/0/0]shutdown

    ปิด interface (undo shutdown เพื่อเปิด)

  • [R1-GigabitEthernet0/0/0]description To-SW1

    คำอธิบาย interface

  • [R1]interface LoopBack 0

    interface เสมือนที่ไม่มีวัน down

  • <R1>display ip interface brief

    IP และสถานะทุก interface

  • <R1>display interface GigabitEthernet 0/0/0

    รายละเอียด, error, ความเร็ว

  • <R1>display interface brief

    สถานะ physical/protocol และการใช้ bandwidth

  • <R1>display arp

    ตาราง ARP

  • <R1>ping -c 10 -s 1400 10.0.0.2

    ping 10 ครั้ง ขนาด 1400 byte

  • <R1>tracert 10.0.0.2

    ไล่เส้นทางไปปลายทาง

Static route

บทเรียน M4 →
  • [R1]ip route-static 192.168.3.0 24 10.0.12.2

    static route ระบุ next hop

  • [R1]ip route-static 192.168.3.0 24 GigabitEthernet 0/0/1

    ระบุ outbound interface (เหมาะกับ P2P)

  • [R1]ip route-static 0.0.0.0 0 203.0.113.1

    default route

  • [R1]ip route-static 0.0.0.0 0 198.51.100.1 preference 70

    floating static route (สำรอง, default preference = 60)

  • [R1]ip route-static 192.168.3.0 24 NULL 0

    black-hole route ป้องกัน loop เมื่อสรุปเส้นทาง

  • <R1>display ip routing-table

    ตาราง routing ทั้งหมด

  • <R1>display ip routing-table protocol static

    เฉพาะ static route

  • <R1>display ip routing-table 192.168.3.1

    route ที่ใช้กับปลายทางนี้ (longest match)

OSPF

บทเรียน M5 →
  • [R1]ospf 1 router-id 1.1.1.1

    เปิด OSPF process และกำหนด router ID

  • [R1-ospf-1]area 0

    เข้า area 0 (backbone)

  • [R1-ospf-1-area-0.0.0.0]network 10.0.12.0 0.0.0.255

    เปิด OSPF บน interface ที่อยู่ในช่วงนี้ (ใช้ wildcard)

  • [R1-ospf-1]bandwidth-reference 10000

    reference bandwidth (Mbit/s) ต้องตั้งเหมือนกันทุกตัว

  • [R1-ospf-1]default-route-advertise always

    ประกาศ default route เข้า OSPF

  • [R1-ospf-1]silent-interface GigabitEthernet 0/0/2

    ไม่ส่ง Hello ออกพอร์ตฝั่งผู้ใช้

  • [R1-GigabitEthernet0/0/0]ospf cost 10

    กำหนด cost ของ interface

  • [R1-GigabitEthernet0/0/0]ospf dr-priority 0

    ไม่ลงสมัคร DR/BDR

  • [R1-GigabitEthernet0/0/0]ospf timer hello 5

    เปลี่ยน hello interval (ต้องตรงกับ neighbor)

  • [R1-GigabitEthernet0/0/0]ospf network-type p2p

    เปลี่ยนชนิด network (ไม่เลือก DR)

  • [R1-GigabitEthernet0/0/0]ospf authentication-mode md5 1 cipher Huawei@123

    authentication บน interface

  • <R1>display ospf peer brief

    neighbor และ state (Full?)

  • <R1>display ospf interface

    DR/BDR, cost, network type ของแต่ละ interface

  • <R1>display ospf lsdb

    LSDB

  • <R1>display ospf routing

    route ที่ OSPF คำนวณได้

  • <R1>reset ospf process

    รีสตาร์ท OSPF (ให้ router ID/DR ใหม่มีผล)

    VLAN ที่อนุญาตผ่าน trunk

  • [SW1-GigabitEthernet0/0/24]port trunk pvid vlan 99

    native VLAN (frame untagged) ของ trunk

  • [SW1-GigabitEthernet0/0/2]port link-type hybrid

    พอร์ต hybrid (ค่า default ของหลายรุ่น)

  • [SW1-GigabitEthernet0/0/2]port hybrid tagged vlan 10 20

    VLAN ที่ส่งออกแบบมี tag

  • [SW1-GigabitEthernet0/0/2]port hybrid untagged vlan 30

    VLAN ที่ถอด tag ก่อนส่งออก

  • [SW1-GigabitEthernet0/0/2]port hybrid pvid vlan 30

    VLAN ของ frame untagged ที่เข้ามา

  • [SW1]port-group group-member GigabitEthernet 0/0/1 to GigabitEthernet 0/0/10

    ตั้งค่าหลายพอร์ตพร้อมกัน

  • [SW1]interface Vlanif 10

    interface layer 3 ของ VLAN (gateway)

  • [R1-GigabitEthernet0/0/1.10]dot1q termination vid 10

    sub-interface ของ router-on-a-stick

  • [R1-GigabitEthernet0/0/1.10]arp broadcast enable

    ให้ sub-interface ส่ง/รับ ARP broadcast ได้

  • <SW1>display vlan

    VLAN และพอร์ตสมาชิก

  • <SW1>display port vlan

    link-type, PVID, VLAN ที่อนุญาตของแต่ละพอร์ต

  • <SW1>display mac-address

    ตาราง MAC

STP / Eth-Trunk / Smart Link

บทเรียน M7 →
  • [SW1]stp mode rstp

    เลือก STP mode (default mstp)

  • [SW1]stp root primary

    เป็น root bridge (priority 0)

  • [SW1]stp priority 4096

    ตั้ง priority (ผลคูณของ 4096)

  • [SW1-GigabitEthernet0/0/1]stp cost 2000

    ตั้ง path cost ของพอร์ต

  • [SW1-GigabitEthernet0/0/5]stp edged-port enable

    edge port ต่อ host เข้า forwarding ทันที

  • [SW1]stp bpdu-protection

    ปิดพอร์ต edge ที่ได้รับ BPDU

  • <SW1>display stp brief

    role และ state ของแต่ละพอร์ต

  • [SW1]interface Eth-Trunk 1

    สร้าง Eth-Trunk

  • [SW1-Eth-Trunk1]mode lacp

    ใช้ LACP (default manual load-balance)

  • [SW1-Eth-Trunk1]trunkport GigabitEthernet 0/0/1 to 0/0/3

    เพิ่มพอร์ตสมาชิก

  • [SW1-Eth-Trunk1]max active-linknumber 2

    จำนวน active link สูงสุด (LACP)

  • [SW1]lacp priority 100

    LACP system priority (ต่ำกว่าเป็น actor)

  • [SW1-Eth-Trunk1]load-balance src-dst-ip

    วิธีกระจายโหลด

  • <SW1>display eth-trunk 1

    สถานะสมาชิกและ LACP

  • [SW1]smart-link group 1

    สร้าง Smart Link group

  • [SW1-smlk-group1]port GigabitEthernet 0/0/1 master

    กำหนด master port

  • [SW1-smlk-group1]port GigabitEthernet 0/0/2 slave

    กำหนด slave port

  • [SW1-smlk-group1]restore enable

    สลับกลับไป master เมื่อฟื้น (revertive)

  • <SW1>display smart-link group 1

    สถานะ Smart Link

ACL และ AAA

บทเรียน M8 →
  • [R1]acl 2000

    basic ACL (source)

  • [R1-acl-basic-2000]rule 5 deny source 10.1.20.0 0.0.0.255

    rule แบบ basic

  • [R1]acl 3000

    advanced ACL

  • [R1-acl-adv-3000]rule permit tcp source 10.1.10.0 0.0.0.255 destination 10.1.100.10 0 destination-port eq 80

    rule แบบ advanced ระบุ protocol/port

  • [R1-GigabitEthernet0/0/0]traffic-filter inbound acl 3000

    ใช้ ACL กรอง traffic (ไม่ match = permit)

  • <R1>display acl 3000

    rule และจำนวนครั้งที่ match

  • [R1]aaa

    เข้า AAA view

  • [R1-aaa]local-user admin password irreversible-cipher Huawei@123

    สร้าง local user

  • [R1-aaa]local-user admin service-type ssh telnet

    บริการที่ user ใช้ได้

  • [R1-aaa]local-user admin privilege level 15

    สิทธิ์ของ user

  • [R1-aaa]authentication-scheme auth1

    สร้าง authentication scheme

  • [R1-aaa-authen-auth1]authentication-mode radius local

    RADIUS ก่อน ถ้าไม่ตอบใช้ local

  • [R1-aaa]domain huawei

    สร้าง domain แล้วผูก scheme

  • <R1>display local-user

    รายชื่อ local user
