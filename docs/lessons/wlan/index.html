WLAN

WLAN

วัตถุประสงค์

  • บอกมาตรฐาน IEEE 802.11 และ Wi-Fi generation ที่สำคัญได้
  • เปรียบเทียบ Fat AP, Fit AP + AC, cloud AP และรูปแบบการวาง AC (in-path / off-path)
  • อธิบาย CAPWAP, ขั้นตอน AP online และการเชื่อมต่อของ STA
  • เข้าใจความแตกต่างของ direct forwarding กับ tunnel forwarding
  • ตั้งค่า WLAN พื้นฐานบน AC ด้วย profile ต่าง ๆ ได้

มาตรฐาน WLAN

WLAN ใช้คลื่นวิทยุตามมาตรฐาน IEEE 802.11 ส่วน Wi-Fi คือชื่อการรับรองของ Wi-Fi Alliance

มาตรฐานชื่อ Wi-Fiย่านความถี่ความเร็วสูงสุด (ทฤษฎี)
802.11b—2.4 GHz11 Mbit/s
802.11a—5 GHz54 Mbit/s
802.11g—2.4 GHz54 Mbit/s
802.11nWi-Fi 42.4 / 5 GHz600 Mbit/s
802.11acWi-Fi 55 GHz6.9 Gbit/s
802.11axWi-Fi 62.4 / 5 GHz9.6 Gbit/s
  • ย่าน 2.4 GHz มีช่องที่ ไม่ทับซ้อนกันเพียง 3 ช่อง: 1, 6, 11 — ทะลุสิ่งกีดขวางดีกว่าแต่สัญญาณรบกวนมาก
  • ย่าน 5 GHz มีช่องมากกว่า สัญญาณรบกวนน้อยกว่า แต่ระยะสั้นกว่า

อุปกรณ์และสถาปัตยกรรม

แบบลักษณะเหมาะกับ
Fat APAP ทำงานเองทั้งหมด ตั้งค่าทีละตัวบ้าน, ร้านเล็ก
AC + Fit APAC (Access Controller) จัดการ config/ผู้ใช้/RF ส่วน Fit AP ทำแค่ส่งรับสัญญาณองค์กรขนาดกลาง–ใหญ่

การวาง AC:

  • In-path — traffic ของผู้ใช้วิ่งผ่าน AC เสมอ (AC อยู่บนเส้นทางหลัก)
  • Off-path (bypass) — AC ต่อข้างสวิตช์ core จัดการเฉพาะ control ส่วนข้อมูลจะผ่าน AC หรือไม่ขึ้นกับ forwarding mode ✓ นิยมในเครือข่ายเดิมที่มีอยู่แล้ว

คำศัพท์

  • STA — อุปกรณ์ปลายทางไร้สาย
  • SSID — ชื่อเครือข่ายที่ผู้ใช้เห็น
  • BSSID — MAC ของ radio บน AP ที่ให้บริการ SSID นั้น
  • BSS / ESS — พื้นที่ของ AP เดียว / หลาย AP ที่ใช้ SSID เดียวกันให้ผู้ใช้ roaming ได้
  • VAP — AP เสมือน — radio เดียวให้บริการหลาย SSID ได้ (แต่ละ SSID คือ VAP หนึ่งตัว)

CAPWAP

AC กับ Fit AP คุยกันด้วย CAPWAP ผ่าน UDP:

  • Control tunnel — UDP 5246 (ตั้งค่า, จัดการ, ตรวจสถานะ)
  • Data tunnel — UDP 5247 (ข้อมูลผู้ใช้ เมื่อใช้ tunnel forwarding)

ขั้นตอน AP online

  1. AP ได้ IP (มักจาก DHCP)
  2. AP ค้นหา AC — จาก IP ที่ตั้งไว้, DHCP option 43, หรือ broadcast discovery
  3. สร้าง CAPWAP tunnel
  4. AC ตรวจสิทธิ์ AP (auth mode: mac-auth, sn-auth, no-auth)
  5. อัปเกรดซอฟต์แวร์ AP ถ้าจำเป็น
  6. AC ส่ง configuration ลงไปที่ AP แล้ว AP ให้บริการ SSID

STA เชื่อมต่อ

Scanning (passive: ฟัง Beacon / active: ส่ง Probe Request) → Link authentication → Association → Access authentication (เช่น WPA2-PSK หรือ 802.1X) → ขอ IP ด้วย DHCP

🎯 จุดที่มักออกสอบ

  • ลำดับ profile: ssid-profile + security-profile → vap-profile → ap-group (ผ่าน vap-profile ... wlan <id> radio <n>)
  • CAPWAP control 5246 / data 5247 · AP หา AC ผ่าน DHCP option 43
  • 2.4 GHz ช่องไม่ทับซ้อน 1/6/11 · Wi-Fi 6 = 802.11ax

สรุปท้ายบท

  • 802.11n/ac/ax = Wi-Fi 4/5/6
  • Fit AP + AC ใช้ CAPWAP (UDP 5246/5247)
  • AP online: IP → discover AC → CAPWAP → auth → upgrade → config
  • direct forwarding ลดภาระ AC, tunnel forwarding ควบคุมที่ศูนย์กลาง
  • ตั้งค่าด้วย profile แล้วผูกเข้ากับ ap-group
