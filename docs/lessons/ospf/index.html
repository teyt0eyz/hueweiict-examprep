OSPF

OSPF

วัตถุประสงค์

  • อธิบายความแตกต่างของ distance-vector กับ link-state และจุดเด่นของ OSPF
  • บอกการเลือก Router ID, ชนิด packet, neighbor state machine และ network type ของ OSPF ได้
  • อธิบายการเลือก DR/BDR และเหตุผลที่ต้องมี DR บน broadcast network
  • คำนวณ OSPF cost และเส้นทางที่ดีที่สุดด้วย SPF ได้
  • ตั้งค่า OSPF single-area และ multi-area บน VRP และอ่านผล display ได้

ทำไมต้อง dynamic routing

static route ไม่ปรับตัวเมื่อ topology เปลี่ยน และดูแลยากเมื่อเครือข่ายใหญ่ dynamic routing protocol ให้ router แลกข้อมูลกันเองและคำนวณเส้นทางใหม่อัตโนมัติ

OSPF (Open Shortest Path First) เป็น IGP มาตรฐานเปิด รุ่นที่ใช้กับ IPv4 คือ OSPFv2 ทำงานบน IP โดยตรง protocol number 89 ใช้ multicast 224.0.0.5 (ทุก OSPF router) และ 224.0.0.6 (DR/BDR)

คำศัพท์สำคัญ

  • Router ID — เลข 32 bit ที่ไม่ซ้ำกันใน OSPF domain ลำดับการเลือก: กำหนดเองใน process (ospf 1 router-id x.x.x.x) → router id ระดับระบบ → IP ของ loopback สูงสุด → IP ของ interface อื่นที่สูงสุด เมื่อเปลี่ยน router ID ต้อง reset ospf process จึงจะมีผล
  • Area — แบ่ง LSDB ให้เล็กลง Area 0 คือ backbone ทุก area ต้องต่อเข้ากับ area 0
  • ABR (Area Border Router) — มี interface อยู่ใน area 0 และ area อื่น
  • ASBR — นำ route จากภายนอก (เช่น static, default) เข้ามาใน OSPF
  • Cost — ค่า metric ของ interface = reference bandwidth / bandwidth ของ interface (Huawei default reference = 100 Mbit/s, cost ต่ำสุด = 1)

ชนิดของ OSPF packet

Typeชื่อหน้าที่
1Helloค้นหาและรักษา neighbor, เลือก DR/BDR
2DD (Database Description)ส่งรายการสรุป LSA ใน LSDB
3LSR (Link State Request)ขอ LSA ที่ตัวเองยังไม่มี
4LSU (Link State Update)ส่ง LSA ตัวจริง
5LSAckยืนยันการได้รับ LSU

Neighbor state machine

Down → Init → 2-Way → ExStart → Exchange → Loading → Full
  • Down — ยังไม่ได้ Hello จากอีกฝั่ง
  • Init — ได้รับ Hello แต่ยังไม่เห็น Router ID ของเราในนั้น
  • 2-Way — เห็นตัวเองใน Hello แล้ว = เป็น neighbor (บน broadcast network จะเลือก DR/BDR ในช่วงนี้)
  • ExStart — ตกลง master/slave (Router ID สูงกว่าเป็น master) และ DD sequence
  • Exchange — แลก DD
  • Loading — ส่ง LSR / LSU เพื่อเติม LSA ที่ขาด
  • Full — LSDB ตรงกัน = adjacency สมบูรณ์

🎯 จุดที่มักออกสอบ

บน broadcast network DROther กับ DROther จะค้างอยู่ที่ 2-Way ตลอด (ไม่ใช่ปัญหา) และจะ Full กับ DR และ BDR เท่านั้น — โจทย์ชอบให้ดู display ospf peer brief แล้วถามว่าผิดปกติไหม

เงื่อนไขที่ต้องตรงกันจึงเป็น neighbor ได้: Hello/Dead interval, Area ID, authentication, subnet mask (บน broadcast), stub flag และ Router ID ต้อง ไม่ซ้ำกัน — ส่วน process ID ต่างกันได้เพราะมีผลเฉพาะในเครื่อง

DR และ BDR

ถ้ามี n router บน segment เดียวกันแล้วทุกตัว Full กันหมดจะได้ adjacency n(n−1)/2 คู่ OSPF จึงเลือก DR (Designated Router) เป็นศูนย์กลางรับ-ส่ง LSA และ BDR เป็นตัวสำรอง router อื่น (DROther) จะ Full กับ DR/BDR เท่านั้น

กติกาการเลือก (ต่อ interface/segment ไม่ใช่ต่อ router):

  1. DR priority สูงสุดชนะ (default 1, ช่วง 0–255) — priority 0 = ไม่มีสิทธิ์ เป็น DR/BDR
  2. ถ้าเท่ากัน Router ID สูงสุดชนะ
  3. การเลือกเป็นแบบ non-preemptive — ถ้า DR มีอยู่แล้ว router ใหม่ที่ priority สูงกว่าจะไม่แย่งตำแหน่ง จนกว่า DR/BDR จะล่มหรือ reset process

ในรูปถ้าทุกตัวเริ่มพร้อมกัน: R3 (priority 0) ตกรอบ R4 (RID สูงสุด) ได้ DR และ R2 ได้ BDR

Cost และ SPF

cost ของเส้นทาง = ผลรวม cost ของ interface ขาออก ตลอดทาง (รวม cost ของ subnet ปลายทางเอง)

จาก R1 ไป 10.4.4.0/24:

  • R1 → R2 → R4 = 10 + 10 + 1 = 21
  • R1 → R3 → R4 = 1 + 30 + 1 = 32
  • R1 → R3 → R2 → R4 = 1 + 5 + 10 + 1 = 17 ← ดีที่สุด

⚠️ กับดักที่พบบ่อย

default reference 100 Mbit/s ทำให้ FE, GE และ 10GE มี cost = 1 เท่ากันหมด เครือข่ายจริงควรตั้ง bandwidth-reference ให้สูงขึ้น (เช่น 10000) บนทุก router ให้เหมือนกัน ไม่เช่นนั้นเส้นทางที่แต่ละตัวคำนวณจะไม่สอดคล้องกัน

สามตารางของ OSPF

  1. Neighbor table — display ospf peer [brief]
  2. LSDB — display ospf lsdb
  3. Routing table — display ospf routing และ route ที่ชนะจะถูกติดตั้งใน IP routing table (display ip routing-table protocol ospf)

LSA ที่ควรรู้: Type 1 Router-LSA (ทุก router สร้าง อยู่ใน area), Type 2 Network-LSA (DR สร้าง), Type 3 Summary-LSA (ABR สรุป route ข้าม area), Type 4 ASBR-summary, Type 5 AS-external (ASBR)

ตั้งค่า OSPF single-area

⚠️ กับดักที่พบบ่อย

คำสั่ง network ใน OSPF ของ VRP ใช้ wildcard mask (0.0.0.255) ถ้าใส่ 255.255.255.0 จะได้ความหมายต่างไปโดยสิ้นเชิง และคำสั่ง network ไม่ได้บอกว่าจะประกาศ subnet อะไร แต่บอกว่า interface ไหนจะรัน OSPF

สรุปท้ายบท

  • OSPF = link-state, IP protocol 89, multicast 224.0.0.5 / 224.0.0.6, preference 10 (ASE 150)
  • 5 packet: Hello, DD, LSR, LSU, LSAck · 7 state: Down → … → Full
  • DR: priority สูงสุด → RID สูงสุด, priority 0 ไม่เข้าร่วม, non-preemptive
  • cost = 100 Mbit/s / BW (min 1) รวมตาม interface ขาออก
  • network ใช้ wildcard · area 0 เป็น backbone · ABR สรุปด้วย abr-summary
