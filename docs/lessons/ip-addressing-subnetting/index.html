IP Addressing & Subnetting

IP Address และการแบ่ง Subnet

วัตถุประสงค์

  • แปลงเลขฐานสองและฐานสิบได้คล่อง
  • แยก network part / host part ด้วย subnet mask และบอก class, address พิเศษ, private address ได้
  • คำนวณ network, broadcast, ช่วง host และจำนวน host ของ subnet ใด ๆ ได้ภายในไม่กี่วินาที
  • ออกแบบ FLSM และ VLSM จาก address block ที่กำหนดได้
  • รวม subnet (route summarization / supernetting) และหาว่า IP อยู่ subnet ไหนได้

ตารางนี้ใช้ได้ทุกโจทย์: รู้ prefix → รู้ mask ใน octet ที่ "ไม่ใช่ 0 หรือ 255" → รู้ block size → ไล่หา subnet

โครงสร้าง IPv4 address

IPv4 ยาว 32 bit เขียนเป็น dotted decimal 4 octet แบ่งเป็น network part (ดูจาก mask ที่เป็น 1) และ host part (mask ที่เป็น 0)

  • Network address — host bits เป็น 0 ทั้งหมด ใช้แทนตัว subnet ใช้เป็น IP ของเครื่องไม่ได้
  • Broadcast address — host bits เป็น 1 ทั้งหมด ส่งถึงทุกเครื่องใน subnet
  • จำนวน host ที่ใช้ได้ = 2h − 2 (h = จำนวน host bits)
  • Gateway — IP ของ router ใน subnet เดียวกับ host ใช้ส่ง packet ออกนอก subnet

วิธีคำนวณ subnet แบบเร็ว

ตัวอย่าง: 10.20.77.200/21

  1. /21 → octet ที่ "น่าสนใจ" คือ octet ที่ 3 (16 < 21 ≤ 24) มี mask bit ใน octet นั้น 5 bit → mask 255.255.248.0
  2. block size = 256 − 248 = 8 → subnet ใน octet 3 คือ 0, 8, 16, … 72, 80, …
  3. 77 อยู่ในช่วง 72–79 → network = 10.20.72.0
  4. broadcast = network ถัดไป − 1 = 10.20.79.255
  5. host ใช้ได้ 10.20.72.1 – 10.20.79.254 จำนวน 211 − 2 = 2046

⚠️ กับดักที่พบบ่อย

host range ข้าม octet ได้ — 10.20.72.255 เป็น host ที่ใช้ได้ ใน /21 นี้ ไม่ใช่ broadcast เพราะ broadcast คือ 10.20.79.255

FLSM และ VLSM

  • FLSM (Fixed-Length) — แบ่งทุก subnet ขนาดเท่ากัน ยืม n bit ได้ 2n subnet
  • VLSM (Variable-Length) — แต่ละ subnet ใช้ mask ไม่เท่ากันตามจำนวน host จริง ประหยัด address กว่า

⚠️ กับดักที่พบบ่อย

VRP ไม่ยอมให้ IP ของสอง interface บน router เดียวกัน อยู่ subnet ที่ทับซ้อนกัน จะขึ้น error ว่า address conflicts — ถ้าโจทย์ให้ config แบบนี้ แสดงว่าเป็น config ที่ผิด

รวม subnet (Summarization / Supernetting)

ใช้ลดขนาด routing table:

  1. เขียน octet ที่ต่างกันเป็น binary
  2. นับ bit ที่ เหมือนกันจากซ้ายต่อเนื่อง → นั่นคือ prefix ใหม่
  3. ตั้ง bit ที่เหลือเป็น 0 ได้ network ที่รวมแล้ว

ตัวอย่าง 172.16.12.0/24 – 172.16.15.0/24: 12 = 000011 00, 15 = 000011 11 เหมือนกัน 6 bit → 172.16.12.0/22

🎯 จุดที่มักออกสอบ

  • โจทย์ "subnet ไหนมี host ได้อย่างน้อย N เครื่อง" → หา h ที่เล็กที่สุดซึ่ง 2h − 2 ≥ N
  • โจทย์ "IP ใดเป็น host ที่ใช้ได้" → ตรวจว่าไม่ใช่ network หรือ broadcast ของ subnet นั้น
  • /31 ใช้ได้กับลิงก์ P2P ตาม RFC 3021 แต่ในข้อสอบ HCIA ส่วนใหญ่คาดว่า P2P ใช้ /30
  • จำนวน subnet จากการยืม n bit คือ 2n (VRP ใช้ subnet zero ได้ปกติ)

สรุปท้ายบท

  • block size = 256 − ค่า mask ใน octet ที่น่าสนใจ
  • network = ตัวคูณของ block size ที่ไม่เกินค่า, broadcast = network ถัดไป − 1
  • host = 2h − 2, subnet = 2n
  • VLSM: เรียงจากใหญ่ไปเล็ก จัดต่อกันไม่ให้ทับซ้อน
  • private: 10/8, 172.16/12, 192.168/16 · APIPA 169.254/16 · loopback 127/8
